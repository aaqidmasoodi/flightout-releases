# FlightOut

Fly the Su-27 over Kashmir. A free combat flight simulator by Yembera.

**Website:** [flightout.app](https://flightout.app)

**Play in your browser:** [run.flightout.app](https://run.flightout.app) (FlightOut Lite, no install)

## Download

Get the latest version from [Releases](https://github.com/aaqidmasoodi/flightout-releases/releases/latest), or from the [download page](https://flightout.app/download).

| Platform | File |
|---|---|
| Windows | `FlightOut-<version>-Windows-Setup.exe` |
| macOS | `FlightOut-<version>-macOS.dmg` (or `.zip`) |
| Linux x86_64 | `FlightOut-<version>-Linux-x86_64.tar.gz` |
| Linux arm64 | `FlightOut-<version>-Linux-arm64.tar.gz` |

Each release has a `SHA256SUMS.txt` to check your download.

FlightOut is in alpha. Older versions are on the [versions page](https://flightout.app/versions).
